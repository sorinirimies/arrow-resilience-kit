class AdaptiveLimiterRegistry(source)

Registry for managing multiple named adaptive limiters.

Example usage:

val registry = AdaptiveLimiterRegistry.create()

val apiLimiter = registry.getOrCreate("downstream-api") {
    initialLimit = 20
}
