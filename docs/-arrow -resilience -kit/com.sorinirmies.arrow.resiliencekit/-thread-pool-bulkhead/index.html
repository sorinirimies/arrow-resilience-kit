ThreadPoolBulkhead

class ThreadPoolBulkhead : AutoCloseable

Thread-pool-isolation bulkhead (JVM). Admitted calls run on a dedicated fixed-size thread pool of BulkheadConfig.maxConcurrentCalls threads, so slow or blocking calls can never consume threads outside the pool.

Must be closed to release its threads.

ThreadPoolBulkhead.create("payments", BulkheadConfig(maxConcurrentCalls = 8)).use { b ->
    b.execute { blockingJdbcCall() }
}
