Cache

class Cache<T>

JS/TS-friendly facade over com.sorinirmies.arrow.resiliencekit.Cache, specialized to string keys (the common case for JS/TS caches) to keep this facade's generics simple.

import { Cache } from "arrow-resilience-kit";

const cache = await Cache.create<User>({ maxSize: 1000, ttlMillis: 300_000 });
const user = await cache.getOrPut("user-123", () => userService.fetch("user-123"));
