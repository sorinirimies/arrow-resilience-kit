MicrometerBridge

object MicrometerBridge

Binds resilience-pattern statistics to a Micrometer MeterRegistry as gauges.

Each bind* function registers a gauge that reads the pattern's current statistics snapshot on every scrape (via MeterRegistry.gauge semantics) — there is no background polling loop to manage or shut down.
