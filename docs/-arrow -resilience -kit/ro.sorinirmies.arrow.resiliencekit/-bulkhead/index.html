Bulkhead

class Bulkhead(source)

Bulkhead pattern implementation for concurrency isolation.

Limits the number of concurrent calls to protect shared resources from overload. When the maximum number of concurrent calls is reached, additional calls are either queued (up to BulkheadConfig.maxWaitingCalls) or rejected immediately.

Basic usage:

val bulkhead = Bulkhead.create(config = BulkheadConfig(maxConcurrentCalls = 5))

val result = bulkhead.execute {
    callExternalService()
}
